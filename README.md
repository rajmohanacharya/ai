# RajAIAssist Local Unified Studio v2.0.1

Upload the contents of this directory to the root of `rajmohanacharya/ai`.

The notebook runtime updates only `runtime-endpoint.json` during a live session. Keep the private master secret, repository update token and workspace credentials in the notebook secret store, never in this public repository.

The public `howto/` page documents owner and guest access, local model profiles, private threads, artifacts and runtime limits.
