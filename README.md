# RajAIAssist GitHub Pages v3.0.0

Upload this directory's contents to the root of `rajmohanacharya/ai`.

Public pages:

- `/ai/` — main RajAIAssist workspace
- `/ai/howto/` — end-user guide, prompt etiquette, do's/don'ts, and advanced prompts
- `/ai/howtoadmin/` — administrator architecture and CLI command manual

v3 includes:

- Garuda-inspired and Apple-inspired themes;
- Ubuntu local/system font stack;
- 1K/2K/4K/8K output selection;
- Balanced and Conservative response controls;
- runtime, context, output, elapsed, and compute badges;
- clipboard paste and drag/drop screenshot OCR ingestion;
- Continue response action;
- owner/guest access separation;
- Local-First Vault status and administration controls;
- multiple-file ingest;
- user and administrator help pages.

When a runtime is online, preserve its current `runtime-endpoint.json` or run
`rajai-colab repair` immediately after deployment so the live endpoint is
republished.
